# LinkedIn Project Description: Inspector Rabbit

**Project:** Inspector Rabbit — Advanced OSINT Intelligence Suite
**Role:** Lead Developer / Security Researcher

**Description:**
Inspector Rabbit is a comprehensive Open Source Intelligence (OSINT) desktop application built with Python and PyQt6. It provides investigators with a centralized hub for cross-platform data gathering, visualization, and analysis.

**Key Technical Achievements in v1.4.0:**
*   **Asynchronous Engine:** Implemented multi-gateway async search for the new Dark Web module, enabling deep-web discovery without local infrastructure overhead.
*   **Memory Management:** Resolved complex threading issues and PyQt6 garbage collection crashes to ensure 99.9% uptime during long-running data collection tasks.
*   **Data Aggregation:** Developed scrapers and API integrations for historical WHOIS data, certificate transparency logs, and 100+ social platforms.
*   **Interactive Visualization:** Built a real-time graph visualization system using NetworkX to map relationships between discovered entities (emails, IPs, domains).

**Tech Stack:** Python, PyQt6, NetworkX, Beautiful Soup, requests/aiohttp, Matplotlib.
